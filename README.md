## 📁 How It Works

1. Connect the controller and verify Windows detects it using `joy.cpl`.
2. Test buttons and axes in Windows Game Controllers before opening the game.
3. In Steam, review the game’s Controller settings and whether Steam Input is enabled or disabled.
4. Avoid running multiple controller mapping layers simultaneously; test one configuration at a time.
5. If input is duplicated or missing, reconnect the controller and reset only the affected profile.

## ❓ FAQ

**Q: Why does a controller work in Windows but not in the game?**  
A: Steam Input mode, the selected layout, or the game’s native controller support may differ. Compare them individually.

**Q: Is this an official Invokyr utility?**  
A: No. This is an independent troubleshooting guide, not an official game release.

- Record the exact error or performance result before and after each change.

- Retest with one change at a time; undo settings that do not help.
